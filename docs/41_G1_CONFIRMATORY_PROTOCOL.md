# 41 | G1 confirmatory evaluation — pre-registration (frozen BEFORE the sealed set is generated and BEFORE any model is trained for it)

Date 2026-11-13. **Scope label:** "same generator, new random seeds" (`configs/sodh/sodh_v2c_confirm.yaml`, new master seed 20261201). It is *not* an independent environment and its structural-OOD splits reuse the v2 mechanisms; it tests replication of G1 behaviours on unseen scene draws, nothing broader.
**Sealing.** The set is generated once, written outside the repository (`~/sealed_uc_vla/sodh_v2c`), never read by training, development or tuning code; only its config and file hashes are committed (`registry/sealed_sodh_v2c.json`). It is evaluated **once** per final model by `scripts/run_g1_confirm.py`; every access is appended to the sealed ledger. If anything is tuned after seeing its results the set is declared **burned** and may not be called unseen again.
**Frozen models (selection fixed now, val-only selection inside each run):** (A) GRU (hidden 64) and (B) fixed-latent S=4, both with docs/25 hyper-parameters, trained on the v2 train split + train-only balanced auxiliary data `configs/sodh/g1_trainaug_mix_3000.yaml` (3,000 pairs per relevant family; first-seen in docs/39), early stopping on VAL mean PairOptimal; **5 training seeds (0–4)**; no further hyper-parameter or data-mixture change. The Transformer is excluded (failed in G1; not re-tuned here).
**Primary metrics:** per relevant family, `test_id`-type PairOptimal; secondary: swap-follow, critical-minus-non-critical deletion drop, memoryless PairOptimal, order-perturbation drop (track), control accuracy/swap-invariance, structural-OOD and length-OOD PairOptimal, counterfactual (resume; item names are canonicalised, so not an identity test).
**Criteria (ALL must hold; implemented in `scripts/aggregate_g1.py::apply_criteria`, unit-tested including the order condition):** ≥2 of 3 families with PairOptimal mean ≥0.60 and lower bound >0.20, swap-follow ≥0.70, drop gap ≥0.20, memoryless ≤0.05, seed range ≤0.25; control ≥0.95 and invariant; **track order-perturbation drop ≥0.15**. Verdict is per architecture. Event length-OOD is reported as a separate pre-declared failure analysis (no pass/fail threshold; expected degradation to be quantified, not hidden).
**Uncertainty (all reported, bounded in [0,1]):** (i) pair level — percentile bootstrap of pair-both-correct within a seed; (ii) scene/template level — pairs are unique templates, so the pair is the scene unit; (iii) training-seed level — min/max and t-interval clipped to [0,1] across 5 seeds; (iv) two-stage bootstrap (seeds × pairs) for the headline interval. Wilson intervals for episode-level rates.
**Not allowed:** re-running training with a different seed set after seeing sealed results and reporting only the better; changing criteria; dropping failed seeds (failed runs are reported).
